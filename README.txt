PALESTINE HISTORY WEBSITE
=========================

FILES
-----
index.html       = Page 1, history overview

overview.html    = Page 2, the two visual posters

styles.css       = All colours, spacing, fonts and layout

script.js        = Hamburger menu only

images/          = The two poster images


HOW TO EDIT
-----------
1. Edit text in index.html or overview.html.
2. Edit colours and appearance in styles.css.
3. The colour table is near the top of styles.css.
4. You normally do not need to change script.js.
5. Keep all these files and the images folder together.


PUBLISHING ON GITHUB PAGES
--------------------------
Upload all files and the images folder to the same repository.
GitHub Pages will normally open index.html as the home page.
